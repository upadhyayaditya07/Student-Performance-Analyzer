# Project Statement — Student Performance Analyzer

## Problem Statement
Manual analysis of student marks is repetitive and makes it difficult to quickly identify class averages, subject performance, grades, and top performers. The project provides a command-line Python solution for entering, validating, searching, sorting, and analyzing student performance records.

## Scope
The system focuses on in-memory academic records for a small class. It supports student entry, validation, search, statistical analysis, selection-sort based ranking, grading, subject summaries, and top-performer reporting. Persistent database storage and GUI features are outside the current scope.

## Target Users
- Students learning programming and algorithmic problem solving
- Faculty members demonstrating basic academic-data analysis
- Beginners practicing Python data structures and control flow

## High-Level Features
1. Student record creation with validation
2. Student ID search using linear search
3. Class and subject statistics using counting, summation, max/min
4. Grade calculation using conditional logic
5. Ranking using selection sort
6. Command-line reports for students, statistics, subjects, and top performers
